videre gets better through the people who use it. Whether something broke,
something surprised you, or you have an idea for what it should do next, we
would love to hear from you.

## Email

Write to [feedback@videre.sh](mailto:feedback@videre.sh). Anything is welcome:
a bug, a question, a feature you miss, or a note that something worked well.
Screenshots and short screen recordings help a lot, so attach them if you can.

## GitHub

If you have a GitHub account, you can also:

- [open an issue](https://github.com/aegea-dev/videre/issues/new) for a bug
  or a feature request, where others can follow and add to it;
- [send a pull request](https://github.com/aegea-dev/videre/pulls) if you
  would like to fix or improve something yourself. These pages live in the
  same repository, under
  [`docs/`](https://github.com/aegea-dev/videre/tree/main/docs), so a
  correction to them is a pull request too.

## What helps in a bug report

- The output of `videre --version` and your operating system.
- The command you ran, or the gallery page you were on.
- What you expected, and what happened instead, with any error text.
- The log for that command, if there is one: `.videre/logs/<command>.log` in
  your library (see [Logging and error handling](/guides/logging-and-errors/)).
  Look it over first: it names your files and folders.

Thank you for taking the time.
